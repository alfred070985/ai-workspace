# 每周建议处理记录

每周记录命名为 `YYYY-Www.md`，例如 `2026-W48.md`。本目录只保存正式处理记录，候选正文位于各自的 `jy/...` 分支。

每份周记录包含：

```markdown
# YYYY-Www 建议归拢

## 本周范围与截止时间
## 默认整合者与 base_commit
## 建议清单（分支、来源、主题、base_commit）
## 接收内容及进入位置
## 拒绝或暂缓内容及理由
## 实际修改文件与验证结果
## 用户每周总确认
## 已删除分支与仍保留分支
```

只有完成周记录、验证和用户总确认后，才能删除已处理建议分支。暂缓或存在疑问的建议必须保留，不能为了“清零”而删除。
