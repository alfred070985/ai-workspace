## 3. 工作约束

- 修改前先确认当前 Git 状态；不得覆盖未提交改动。
- 不执行 `git reset --hard`、`git clean -fd` 或任何不可逆删除操作。
- 不提交 `.env`、凭证、私钥、Cookie、`config.local.yaml` 或本机绝对路径。
- 大型二进制或数据文件按项目 `.gitattributes` 使用 Git LFS。
- 生产查询、线上接口或外部服务调用必须遵守项目列出的访问方式；失败时记录真实阻塞，不紧密重试。
