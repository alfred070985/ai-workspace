# 全局思考协议激活与同步

协议唯一真源是本仓库的 `thinking/CORE.md`。Git 同步真实内容，软链接只做本机定位，工具全局配置负责新会话自动加载；三者不能相互替代。

## 1. 新会话自动加载

将以下内容加入目标工具官方支持的全局指令入口：

```text
每次新会话读取并遵循 ~/.thinking/CORE.md，按任务复杂度选择执行强度。简单任务保持轻量，复杂任务执行完整的目标、事实、行动、验证和交付闭环。用户明确要求的本次任务产出属于已授权范围；额外修复、环境变更和 Git 写操作必须另行确认。不要复述协议，不增加不必要的流程。无法读取协议时如实说明，不得擅自创建、修复或修改环境。
```

仅创建软链接不会触发自动加载。修改任何工具配置前，先核实当前版本的官方入口、备份原文件并说明变更，取得用户确认后再操作；不支持全局引用的工具明确降级为手动触发。

## 2. 老会话触发

触发词：**启用思考协议**。

首次在老会话中发送：

```text
启用思考协议：读取 ~/.thinking/CORE.md；如果本机尚未建立软路径，则读取 ~/ai-workspace/control/thinking/CORE.md。此后在当前会话的每轮任务中，根据复杂度自行选择使用强度。简单任务保持轻量，复杂任务执行完整闭环。用户明确要求的本次任务产出属于已授权范围；额外修复、环境变更和 Git 写操作必须另行确认。不要复述协议。此设置仅对当前会话有效。
```

辅助口令：

- **本次使用思考协议**：只对当前任务生效。
- **停用思考协议**：停止当前会话的主动选择模式，系统原有安全规则不受影响。

## 3. 其他电脑加载控制仓库

在具备文件、Git 和终端能力的工具中使用：

```text
请读取 ~/ai-workspace/control/README.md、~/ai-workspace/control/CONTINUE_PROMPT.md 和 ~/ai-workspace/control/thinking/CORE.md。以仓库文件为事实源，不假设能看到其他设备的历史会话。只读取当前任务需要的文件，不把整个仓库无差别注入上下文。额外修复、环境变更和 Git 写操作，必须先获得我的明确确认。
```

没有文件、Git 或终端能力的工具，需要直接粘贴 `CORE.md` 或下方的便携指令；仅提供 GitHub URL 不代表工具已经加载仓库。

## 4. 无仓库访问能力时的便携指令

```text
请在后续任务中按复杂度采用全局思考与验证协议：简单任务保持轻量，复杂任务明确目标与完成标准，区分事实、假设、推断和偏好，接触真实来源或实际产物，用与结论匹配的方法验证，并说明证据覆盖范围和未验证部分；不得编造来源、执行或验证结果。用户明确要求的本次任务产出属于已授权范围，但排查和诊断不等于修复授权，即使知道修法也必须先说明证据、具体操作、影响、风险、验证与回滚方案并取得当次确认；额外环境变更、验证造成的任务外副作用及 Git 写操作同样先确认。每次对话或阶段收尾时，如发现可跨任务、项目或工具复用的共性方法，请说明来源场景、共性、适用范围、建议入库位置和验证方法，提醒我确认加入；没有候选时不强行提醒，未经确认不修改任何规则或仓库。
```

便携指令只是降级版本；仓库可用时，以 `thinking/CORE.md` 为完整真源。

## 5. 每台电脑初次接入

1. 由用户准备 GitHub 认证，不在仓库保存凭证。
2. 经确认后克隆控制仓库；若目录已存在，先核对远程地址、分支和未提交改动，不覆盖现场。
3. 确认真源文件存在后，再建立本机软链接。macOS / Linux 的逻辑关系为：

   ```text
   ~/.thinking -> ~/ai-workspace/control/thinking
   ```

4. 其他系统使用当前系统支持且经用户确认的等效方式；不擅自提升权限或修复系统配置。
5. 备份并修改目标工具的官方全局指令入口，再验证软路径和文件内容。
6. 用全新会话验证自动加载；老会话验证“启用思考协议”。

## 6. 更新与同步

- 跨电脑内容更新只通过 Git；不需要把文件复制到软链接上。
- 新环境接入或项目续作前，先只读检查远程地址、工作区状态和软链接目标。
- 获取更新遵守 `MULTI_MACHINE_RULES.md` 的 merge 与冲突保护规则；存在未提交改动、身份不符或冲突时停止并报告。
- 拉取后确认 `~/.thinking/CORE.md` 可读且内容与仓库一致；工具若只在启动时读取，需要新开会话或按官方方式重载。
- 默认采用“初次配置 + 续作前检查 + 需要时经确认更新”，不自动创建定时任务或后台同步服务。
- 链接失效、读取失败或校验失败时只报告诊断与修复方案，经确认后才修复。
