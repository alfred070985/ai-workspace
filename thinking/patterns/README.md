# 可复用 AI 范式

本目录保存经用户确认、具有跨任务或跨项目复用价值的思考与工作范式。这里是候选的主要沉淀位置，避免 `../CORE.md` 随经验增加而膨胀。

## 入库门槛

- 来自真实问题，并能说明共性、适用范围和验证方法；
- 重复出现，或一次出现但具有明确普遍价值；
- 已与现有范式去重，并检查与核心协议、项目规则的冲突；
- 已去除凭证、业务隐私、本机绝对路径和其他项目专有数据；
- 未经用户确认不得入库，Git 提交与推送仍需单独确认。

单次偏好、临时绕过方法、未复验的偶然成功和单一业务项目规则不得直接提升为全局范式。

## 文件格式

文件名使用简短、稳定的英文 `kebab-case.md`，内容包含：

```markdown
# 范式名称

## 来源问题
## 共性与适用范围
## 方法或步骤
## 验证方法
## 反例与不适用情况
## 来源与确认记录
```

范式被实际使用后发现过宽、冲突或失效时，只提出修改或退役建议，经确认后再变更。
